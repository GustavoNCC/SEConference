# Requsitos del sistema
## Requerimientos funcionales
RF-01. El sistema permitira registrar asistenetes al congreso

RF-02. El sistema permitira consultar las actividades disponibles

RF-03. El sistema permitira registrar un asistensistente a una actividad

RF-04. El sistema permitira cancelar el registro de un asistente a una actividad

RF-05. El sistema permitira registrar ponenetes del congreso

RF-06. El sistema deberá registar ponentes del congreso. Después de verificar que los datos estén completos, deberá comprobar si el correo ya está registrado. Si el correo ya existe, mostrará una advertencia y no hará el nuevo registro.

## Requerimientos no funcionales
RNF-01. La interfaz debe ser accesible desde un navegador web 

RNF-02. El debera mantener la información de registro de manera persistente

RNF-03. Se actualice la base de datos cada media hora
